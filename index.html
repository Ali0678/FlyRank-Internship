Search Intelligence: CTR Opportunity Scoring

Abstract

This project asks whether machine learning can improve the ranking of pages for search-performance review compared with a simple baseline rule. The analysis uses aggregated search and engagement signals from the FlyRank ML Internship dataset and frames the task as decision-support rather than causal inference. A baseline ranking was compared with a machine-learning ranking using a held-out client-based evaluation split. On that evaluation split, the baseline achieved 0.06 Precision@50 while the ML model achieved 0.98 Precision@50. These results are directional evidence that the learned ranking can prioritize the observed target more effectively on this evaluation set, but they do not prove future production performance or causal effects.

Introduction / Problem Statement

Search teams have more pages to review than they can inspect manually. The goal of this project is therefore to rank pages for review so that human attention can be directed toward pages showing measurable search-performance opportunity.

Data

The analysis uses the FlyRank ML Internship warehouse release. The main content-performance data contains daily observations with search and engagement measurements such as impressions, clicks, average position, sessions, engaged sessions, and scroll events.

The modeling dataset contains 105,903 page-level observations. The observed data spans January 27, 2025 through June 30, 2026. The analysis uses public-safe hashed client and content identifiers rather than client names, domains, private queries, or credentials.

Methodology

The unit of analysis is a content page within a client. Features summarize observed search and engagement behavior during the current measurement window.

The target represents whether the page experienced the defined CTR opportunity in the future window. The baseline uses a simple ranking rule, while the ML model learns a ranking from the available signals.

Validation uses a client-level holdout so that the evaluation includes clients not used during training. There were 67,422 training observations from 34 clients and 9,839 test observations from 9 clients. Future-window information was excluded from the model features.

Results

Method Precision@50
Baseline 0.06
ML model 0.98

On the held-out evaluation set, the ML ranking produced substantially higher Precision@50 than the baseline. This is an observed evaluation result and should not be interpreted as proof of production performance.

Limitations & Honest Framing

  • The analysis is observational rather than experimental.
  • The results do not prove that any search-engine algorithm factor caused an outcome.
  • The evaluation measures performance on the available held-out data and does not guarantee future performance.
  • Search behavior can be affected by seasonality, consolidation, changes in demand, and other factors not captured by the model.
  • The output should be treated as decision-support for human review.

Ranked Recommendations

The resulting ranked queue provides a practical review order. Pages near the top of the ranking should be reviewed first because their observed signals match the learned opportunity pattern most strongly.

The recommendation is not to automatically change every highly ranked page. Instead, use the ranking to prioritize human investigation and then consider the appropriate content or metadata action based on the page context.
